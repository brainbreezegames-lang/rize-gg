Pipeline

The tools are the steps.

The server refuses later steps without earlier ones. The companion skill tells the agent not to fight that.

  1. start_task

    Classify the work as Create, Edit, or Recreate. Returns the mode contract and opens a stateful session.

  2. get_playbook

    Pull a product × flow playbook (structure, strategies, forgotten states, never-do). Injected when planning starts — not dumped upfront.

  3. submit_plan

    Critique and approve the plan. Once approved, the plan is the session contract: stages, screens, and constraints.

  4. get_pattern_guide

    Request a pattern guide at the moment a component appears — required states, mistakes, related patterns, minimal code shape.

  5. review

    After every stage: defect hunt, plan drift, brand bans, slop signatures. Blockers fail the stage; fix and re-review.

  6. final_check

    End-of-task gate before ship. Confirms all stages passed review and no open blockers remain on the contract.

Also available: register_brand_rules and get_session for brand bans / palette / type and for inspecting the live contract.
