# Dungeon Heart

A cozy 3D voxel sorting game. Scatter, pick up, and shelve dungeon relics to awaken the crystal at the heart of the hall.

## Play

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Controls

| Input | Action |
|-------|--------|
| WASD / Arrows | Move |
| E / Space / Click | Pick up item |
| Click shelf / pad / F | Place selected item |
| [ ] | Cycle inventory |
| 1–5 | Cast spells |
| Esc | Pause |

## Spells

1. **Jump** — burst of speed/height  
2. **Identify** — reveal item categories  
3. **Loot Magnet** — pull nearby loot  
4. **Unseen Servant** — auto-place selected item  
5. **Scrying Pulse** — highlight the correct shelf  

Fill all five shelves (Armory, Scrolls, Alchemy, Treasury, Trophies) to awaken the Dungeon Heart.

## Stack

Next.js · React Three Fiber · Three.js · Zustand · Tailwind
