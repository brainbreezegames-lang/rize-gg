Install

Wire the MCP. Point at the skill.

Clone the package, install deps, then register the server with your agent. Copy skill/SKILL.md so the pipeline is default behavior.

1. Package setup

From the design-process-engine directory:

npm install
npm run build
# or for local iteration:
npm run dev

Cursor

Add to your MCP config (Cursor Settings → MCP, or .cursor/mcp.json): 

{
  "mcpServers": {
    "design-process-engine": {
      "command": "npx",
      "args": ["tsx", "/absolute/path/to/design-process-engine/src/index.ts"]
    }
  }
}

After build, you can use Node directly:

{
  "mcpServers": {
    "design-process-engine": {
      "command": "node",
      "args": ["/absolute/path/to/design-process-engine/dist/index.js"]
    }
  }
}

Claude Code

Register via CLI or project config:

claude mcp add design-process-engine -- \
  npx tsx /absolute/path/to/design-process-engine/src/index.ts

Or in .mcp.json:

{
  "mcpServers": {
    "design-process-engine": {
      "command": "npx",
      "args": ["tsx", "/absolute/path/to/design-process-engine/src/index.ts"]
    }
  }
}

Generic MCP client

Any stdio MCP host works. Point command at the server entry and leave args empty (or pass your absolute path): 

{
  "name": "design-process-engine",
  "transport": "stdio",
  "command": "node",
  "args": ["/absolute/path/to/design-process-engine/dist/index.js"]
}

Companion skill

Copy or symlink skill/SKILL.md into your agent's skill path so classify → plan → staged build → review is the default path — not something the model invents around.
