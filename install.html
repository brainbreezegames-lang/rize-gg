Install Pipeline Pricing

Ship today

Install the MCP. Not a prompt kit.

Users connect this once. Their agent is then forced through the full pipeline on every UI task. Pick remote (hosted) or local (stdio).

Option A — Remote MCP (fastest)

Paste into Cursor → Settings → MCP (or .cursor/mcp.json). Same shape works for other MCP clients that support URL servers. 

{
  "mcpServers": {
    "design-process-engine": {
      "url": "REPLACE_WITH_PUBLIC_MCP_URL/mcp"
    }
  }
}

Public URL is injected when the host is live. If you see REPLACE_… the host is still booting — refresh in a moment.

Option B — Local stdio (runs on the user’s machine)

From a checkout of this package:

cd design-process-engine
npm install
npm run build
{
  "mcpServers": {
    "design-process-engine": {
      "command": "node",
      "args": ["/absolute/path/to/design-process-engine/dist/index.js"]
    }
  }
}

Or during development:

{
  "mcpServers": {
    "design-process-engine": {
      "command": "npx",
      "args": ["tsx", "/absolute/path/to/design-process-engine/src/index.ts"]
    }
  }
}

Companion skill (required)

Install skill/SKILL.md as an agent skill / rule so the pipeline is default behavior. The server refuses skipped steps; the skill stops the agent from fighting that.
